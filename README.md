# StudentManager

一个基于 Android、Java 和 SQLite 的学生选课管理示例应用。

## 运行

1. 使用 Android Studio 打开项目目录。
2. 让 Android Studio 根据本机 SDK 生成 `local.properties`。
3. 运行 `app` 模块。

首次安装时，应用会自动生成演示数据。演示管理员账号如下：

- 用户名：`demo-admin`
- 密码：`demo123`

自动生成的学生数据使用 `example.com` 邮箱、全零手机号和示例姓名，仅用于本地演示。

## 说明

本仓库不提交 Android Studio 用户配置、本机路径、构建产物、APK 或签名文件。
